# MIRA para uso diario

MIRA es un asistente de finanzas personales que trabaja de forma local: registra movimientos, organiza cuentas, compara presupuesto contra realidad y te ayuda a mantener trazabilidad sin enviar tus datos a terceros.

## Que incluye esta documentacion

- Instalación y arranque con opciones `.exe`, `.zip`, `.flatpak` y `.snap`.
- Configuración inicial disponible en español o ingles.
- Flujos prácticos para gastos, ingresos, ahorro, presupuestos y tarjetas.
- Referencia tecnica del contrato JSON usado por el parser financiero.

## Ruta recomendada

1. Lee `Instalación y Arranque`.
2. Continua con `Primeros Pasos`.
3. Revisa `Guia de la Interfaz`.
4. Usa `Flujos Prácticos` y `FAQ` como referencia rapida.

## Principios de MIRA

- Local first: la base es SQLite y el procesamiento principal funciona offline.
- Finanzas claras: ahorro, gasto operativo y deuda se distinguen para no inflar KPIs.
- Configuración simple: puedes empezar con una cuenta propia o dejar que MIRA cree una cuenta predeterminada.
