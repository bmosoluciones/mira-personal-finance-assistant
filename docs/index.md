# MIRA for everyday use

MIRA is a local-first personal finance assistant: it records transactions, organizes accounts, compares budget versus actuals, and keeps a clean audit trail without sending your data to third parties.

## What this documentation includes

- Installation and launch guidance with `.exe`, `.zip`, `.flatpak`, and `.snap` options.
- First-run configuration available in English and Spanish.
- Practical flows for expenses, income, savings, budgets, and credit cards.
- The JSON contract used by the financial parser.

## Recommended path

1. Start with `Installation and Launch`.
2. Continue with `First Steps`.
3. Review `Interface Guide`.
4. Use `Practical Workflows` and `FAQ` as your quick reference.

## MIRA principles

- Local first: the database is SQLite and the main processing works offline.
- Clear finance logic: savings, operating expense, and debt are separated so KPIs stay meaningful.
- Simple setup: you can create your own account or let MIRA generate a default account automatically.
